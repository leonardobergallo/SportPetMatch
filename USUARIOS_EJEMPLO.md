## 🧪 Cómo Probar la App

### 1. **Probar el Sistema de Matching**
- Inicia sesión con **María**
- Ve a la pantalla "Matching"
- Deberías ver a **Carlos** y otros usuarios
- Haz swipe derecho en **Carlos** para crear un match

### 2. **Probar el Chat**
- Inicia sesión con **María**
- Ve a "Matches"
- Toca el match con **Ana**
- Deberías ver los mensajes de ejemplo
- Envía un nuevo mensaje

### 3. **Probar Eventos**
- Inicia sesión con **María**
- Ve a "Eventos"
- Deberías ver tu evento creado
- Toca el evento de **Ana** (Playdate)
- Únete al evento

### 4. **Probar Mascotas**
- Inicia sesión con **Ana**
- Ve a "Mascotas"
- Deberías ver 3 mascotas (Luna, Rocky, Mimi)
- Toca una para ver detalles
- Edita o agrega más fotos

### 5. **Probar Perfil**
- Inicia sesión con cualquier usuario
- Ve a "Perfil"
- Toca "Editar Perfil"
- Actualiza tu biografía o intereses

### 6. **Probar Mapa**
- Inicia sesión con cualquier usuario
- Ve a "Mapa"
- Deberías ver marcadores de usuarios y eventos
- Toca un marcador para ver detalles

## 🔄 Para Recrear los Datos

Si necesitas recrear los datos de ejemplo, ejecuta:

```bash
cd backend
npm run db:seed
```

Esto eliminará todos los datos existentes y creará los usuarios de ejemplo nuevamente.
