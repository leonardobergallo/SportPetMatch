Eventos con mascotas

Encontrá y organizá salidas deportivas y encuentros donde humanos y perros comparten la actividad.

Matching

Conocé personas y mascotas compatibles con tus gustos — estilo comunidad, enfocado en el vínculo con tu perro.

Chat

Coordiná encuentros y charlá con otros dueños desde la misma app.

Gamificación

Objetivos y recompensas para mantener el hábito de moverse en equipo con tu mascota.

Perfiles de mascotas

Cada mascota tiene su espacio: datos útiles para matches y eventos seguros.

Gratis para usar

La idea del producto es que descargar y usar la app sea gratuito; el valor está en la comunidad.

React Native (Expo)

App mobile moderna, misma base de código para Android e iOS.

Node + PostgreSQL

Backend con Express y base de datos en la nube (Neon) para escalar cuando llegue el lanzamiento.

MVP en marcha

Todavía no está en Play Store ni App Store: es un proyecto en desarrollo con base sólida.

Comunidad local

Pensado para dueños activos, actividad física y encuentros en tu zona.

Próximo paso: beta

Landing pública, registro simple, un núcleo fuerte (eventos + matching) y APK beta.

Indio · SportPetMatch

App mobile que conecta personas y mascotas para hacer actividades juntos: eventos, matching, chat, gamificación y perfiles de mascotas. Pensada para ser gratuita para los usuarios; más adelante podrían sumarse opciones premium o alianzas locales (eventos, sponsors), sin perder un núcleo accesible para todos.

Estado actual: desarrollo / MVP. No publicada aún en tiendas oficiales.
