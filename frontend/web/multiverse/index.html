INSTALACIÓN

Usá Indio en tu teléfono

El login siempre es en la web (arriba, sección morada): mismo email y contraseña en la app instalada. El APK solo instala el programa en Android; no reemplaza el inicio de sesión.

🍎

iPhone (Safari)

1) Abrí esta web con Safari.
2) Tocá el botón Compartir (cuadrado con flecha hacia arriba).
3) Elegí Agregar a inicio.
4) Abrí el ícono: queda como app. Luego entrá con tu email y contraseña.

🤖

Android (archivo APK)

Google Play aún no tiene la app; por eso el instalador está en GitHub (repositorio del proyecto). El botón de abajo baja el archivo directo: no tenés que navegar GitHub si no querés.

¿Qué es el APK?

Es el paquete que Android usa para instalar apps fuera de la tienda. Es seguro si confiás en el enlace oficial del proyecto.

  1. Tocá Descargar APK y esperá la descarga.
  2. Abrí el archivo desde Descargas o la notificación.
  3. Si pide permiso, permití instalar desde el navegador o archivos.
  4. Abrí Indio e iniciá sesión con el mismo usuario que en la web.
